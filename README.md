## AIM

To use prompt engineering techniques to create and iteratively improve technical and professional communication artifacts using a Large Language Model (LLM).

## OBJECTIVE

To generate and improve the following communication artifacts using effective prompts:

* Technical Report
* Research Abstract
* Literature Review
* Project Proposal
* Resume
* LinkedIn Profile
* Research Poster

The generated outputs are evaluated based on grammar, technical accuracy, plagiarism/originality, and readability.

## AI TOOLS REQUIRED

* ChatGPT
* Plagiarism/Similarity Checker
* Canva or PowerPoint for preparing the research poster

## THEORY

Prompt engineering is the process of designing and refining instructions given to a Large Language Model to obtain a desired output. In technical communication, prompts can be used to generate structured content such as reports, abstracts, literature reviews, project proposals, resumes, LinkedIn profiles, and research posters.

The first response generated by an LLM may contain unnecessary information, generic statements, grammatical issues, or technical inaccuracies. Iterative prompting helps improve the response by providing additional instructions based on the weaknesses identified in the previous output.

The process followed in this experiment is:

**Initial Prompt → Initial Output → Evaluation → Improved Prompt → Improved Output**

---

# PROCEDURE

1. Select **IoT-Based Smart Agriculture Monitoring System** as the common topic for the experiment.
2. Create an initial prompt for each technical communication artifact.
3. Enter the prompt into ChatGPT and record the generated output.
4. Review the output for grammar, technical accuracy, plagiarism/originality, and readability.
5. Identify areas that require improvement.
6. Create an improved prompt addressing the identified issues.
7. Generate the revised output using the improved prompt.
8. Compare the initial and revised outputs.
9. Repeat the refinement process wherever necessary.
10. Compile the final versions of the seven communication artifacts.
